# **App Name**: LinguaTrek

## Core Features:

- Phrasebook: Categorized collection of essential phrases with audio pronunciation.
- Interactive Dialogues: Simulated conversations for common travel scenarios (ordering food, asking for directions, etc.).
- Local Idiom Explanations: AI-powered insights into common local expressions, cultural context, and appropriate usage; the AI will use reasoning as a tool to decide if and when the information is applicable in different situations.
- Record & Compare: Users record their pronunciation of phrases and compare it to a native speaker.
- User Progress Tracking: Monitor user's learning progress, track completed dialogues and practiced phrases.

## Style Guidelines:

- Primary color: Forest green (#6B8E23) evoking nature and approachability.
- Background color: Light beige (#F5F5DC) creating a warm, inviting feel.
- Accent color: Burnt orange (#CC6633) for call-to-actions and highlights, providing a sense of adventure.
- Body and headline font: 'PT Sans', a humanist sans-serif.
- Use custom-designed icons with rounded edges to represent different categories and features. These will contribute to a friendly and accessible feel.
- Clean and intuitive layout with ample spacing for easy readability on mobile devices. Prioritize key phrases and dialogues.
- Subtle transitions and animations to guide users through interactions and provide feedback on their progress.
